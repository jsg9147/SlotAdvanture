# 🎰 Slot Adventure

## 📌 프로젝트 개요
- 개발 기간: 2024.01 ~ 2024.03
- 개발 인원: 1인 개발
- 장르: 확률 기반 로그라이크 RPG
- 플랫폼: PC
- 사용 엔진/언어: Unity, C#

## 🎯 기획 의도
- 모든 전투를 **확률 기반으로 진행**하는 로그라이크 게임으로, 컨트롤 요소 없이 **전략 설계에 집중하는 경험**을 제공
- **컨트롤에 자신 없는 유저들도 플레이 가능한 게임**을 목표로 설계
- 캐릭터, 스킬, 아이템, 이벤트 등 모든 요소에 **랜덤성과 도박 요소**를 추가해 매판 다른 재미를 유도
- 플레이어는 3명의 캐릭터로 시작하며, 캐릭터는 랜덤 스탯과 랜덤 스킬을 지닌다

## 💻 주요 개발 기능
| 기능 | 설명 |
|------|------|
| 확률 기반 전투 시스템 | 각 공격마다 확률을 뽑고, 해당 수치가 공격 성공률이 되며, 성공 여부는 내부 확률 알고리즘으로 결정됨 (ex. 700 → 70% 확률 성공) |
| 슬롯 UI 시스템 | 스킬북 학습 및 확률 시스템에 슬롯 머신 UI를 도입하여, 확률 기반 전략에 시각적인 피드백 제공 |
| 로그라이크 던전 구조 | 층 단위로 진행되며, 보스를 클리어하면 다음 층으로 진입하는 구조 |
| 턴제 파티 시스템 | 플레이어가 각 캐릭터에게 명령을 내리고, 캐릭터는 스피드 스탯에 따라 순차적으로 행동 |
| 버프 시스템 (성소) | 버프를 보유한 캐릭터는 사망 시 한 번 부활 가능. 버프는 별도 클래스로 관리되며, 중복 시 덮어쓰기 및 사망 시 제거 처리 |
| 아이템 시스템 | 장비 아이템은 스탯(체력, 공격력, 방어력) 상승, 소비 아이템은 회복 및 부활 기능 제공 |
| 인벤토리 시스템 | 장비/소모 아이템을 구분하여 관리하는 인벤토리 시스템 구현. UI 슬롯 기반 인터페이스로 아이템 확인, 장착, 사용 가능. 아이템 효과는 데이터 기반으로 처리 |
| 장비 매니저 시스템 | 각 캐릭터에 장비 아이템을 할당하고, 장착 시 캐릭터 스탯에 실시간 반영되도록 설계. 장비 변경 시 이전 장비 해제 처리도 함께 수행 |
| UI 시스템 | 슬롯 확률 표시, 스킬북 학습 인터페이스, 파티 관리, 인벤토리, 장비창 등 다양한 전용 UI 구성 |
| 게임 오버 처리 | 파티 전원 사망 시 게임 오버 처리

## 🧠 설계 및 구조
- **TurnManager**: 캐릭터 및 몬스터의 속도에 따라 행동 순서를 정렬하고, 턴 진행 관리
- **BattleManager**: 1000분율 기반 확률 알고리즘 구현 → 공격 성공률, 아이템 효과 발동 등 모든 확률 계산에 사용
- **SanctuaryManager / Buff 클래스**: 각 캐릭터에 부여된 버프 데이터를 관리하고, 사망 시 자동 제거 처리
- **SkillManager**: 스킬북 학습 시 슬롯 머신 UI로 확률 표시 → 학습 성공 시 특정 캐릭터에 스킬 배정
- **DungeonManager**: 층 단위 진행 구조, 보스 클리어 시 다음 층 이동 처리
- **InventoryManager**: 인벤토리 내 아이템 데이터를 슬롯 UI와 연동하여 장비/소모 아이템 분리 관리
- **ItemData 클래스**: 아이템 ID, 이름, 타입(장비/소모), 효과 등 구조화된 데이터 설계
- **EquipmentManager**: 각 캐릭터별 장비 상태를 추적하고, 장비 장착 시 스탯 반영 및 교체 처리

## 📈 개선 및 회고
- 확률 시스템 설계 시, 직관적인 UX와 전략성을 균형 있게 담아내는 것이 가장 큰 고민이었음  
- 슬롯 머신 UI 구현이 시각적으로 강한 인상을 주었지만, 더 다양한 인터랙션이 추가되었으면 좋았을 것 같음  
- 인벤토리와 장비 시스템은 기능적으론 잘 구성되었으나, 사용자 편의성을 위한 UI 설계는 더 보완할 여지가 있음  
- 던전 구조의 다양성과 스킬 조합 전략성을 향후 확장할 여지가 충분함
